# precious-portfolio

Personal portfolio for **Precious O Oritsedere** — software engineer (product systems, Solid/open data, platforms).

## Stack

Next.js App Router · TypeScript · Tailwind CSS v4 · Motion · Vercel

## Docs

- `PRD.md` — product requirements
- `DESIGN.md` — visual system
- `PLAN.md` — phased build plan

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Env

See `.env.example` for contact email, calendar booking URL, GitHub username, and optional Spotify URL.
